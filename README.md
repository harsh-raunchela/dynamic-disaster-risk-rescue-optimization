# Dynamic Disaster Risk, Evacuation & Rescue Optimization

A C++ and Data Structures & Algorithms based system for optimizing evacuation and rescue operations during dynamic disaster situations.

## Overview

The system models a disaster-affected region as a **dynamic weighted graph**, where roads can change based on risk, traffic, damage, and availability.

It provides:
- Risk-aware route optimization
- Emergency prioritization
- Rescue resource allocation
- Critical road detection
- Dynamic re-routing
- Hospital and shelter selection
- What-if disaster simulation

## Tech Stack

C++, STL, Python, NumPy, Pandas, Scikit-learn, MySQL, React.js, Node.js, Express.js, Leaflet, OpenStreetMap

## Core DSA & Algorithms

**Data Structures:** Graph, Priority Queue, Min Heap, Hash Map, Queue, Set, Stack

**Algorithms:** Dijkstra, BFS, DFS, A*, Bridge & Articulation Point Detection
